Settings

Settings are fixed on this install

This copy of ACP is set up with environment variables, so this page cannot change anything. To use different image folders, set FITS_ROOTS and restart ACP, then start a scan with docker exec or schedule one with ACP_SCAN_CRON. The archive setup guide has the details.

Open this page on the computer that runs ACP

Image folders can only be changed from the computer ACP is running on, or with the access token.

Your image folders

    Open the map

    Catalogues for the map

    The map can show supernova remnants, HII regions, Sharpless objects and planetary nebulae. These lists are not included with ACP. Pressing the button makes ACP connect to the internet (to the VizieR service run by CDS in Strasbourg) and download them. It can take a few minutes.
